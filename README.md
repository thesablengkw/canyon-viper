Canyon Viper is an original, fully offline browser flight game. Pilot the VF-9 Viper, a twin-tail desert interceptor with glowing cyan wingtip lights and a lit glass cockpit, through Viper Gorge: a sunlit red-rock canyon with a winding river, mesa plateaus and golden aerial target rings. Fly the 10-ring time trial, switch to free flight, and land at Viper Field's marked runway (approach lights, tower, hangars) for a touchdown bonus. Keyboard and mouse flight controls cover pitch, roll, yaw, throttle, boost, airbrake and landing gear; the HUD shows altitude, airspeed, heading, an artificial-horizon pitch ladder and the mission score. Jet engine and wind audio is synthesized live with the Web Audio API — no files, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# then serve game/ with any static file server and open index.html in desktop Chrome
```
